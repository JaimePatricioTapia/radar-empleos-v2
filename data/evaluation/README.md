# Dataset de evaluación

Aquí se mantendrá la estructura y documentación del benchmark. No incorporar CV real, datos personales ni ofertas que contengan datos sensibles sin anonimización.

El dataset debe contener texto de oferta anonimizado, referencia humana, versión del CV de prueba y metadatos de procedencia. Los secretos y datos de usuario nunca deben almacenarse aquí.
